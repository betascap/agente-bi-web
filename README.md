# Agente de BI — painéis web interativos

Protótipo acadêmico de um agente que recebe arquivos de dados e ajuda a transformar perguntas de negócio em painéis interativos.

## Demonstração online

Acesse o painel publicado em: <https://betascap.github.io/agente-bi-web/>

O painel de exemplo tem filtros por período e categoria. Os dados exibidos são fictícios e servem apenas para demonstrar a experiência.

## Como o agente foi pensado

A especificação inicial está em [`AGENTE.md`](AGENTE.md). Ela descreve como o agente deve analisar arquivos CSV ou Excel, confirmar indicadores com o usuário, apontar limitações dos dados e gerar um painel web.

## Estado atual

Este repositório contém a especificação e um protótipo interativo. A integração com um modelo de IA e a geração automática de painéis a partir de arquivos enviados ainda não foram implementadas.

## Publicar para compartilhar

O arquivo `index.html` é publicado pelo GitHub Pages a partir da branch `main`. Não há dados reais nem credenciais neste projeto.
