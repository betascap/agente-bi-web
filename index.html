Projeto de Business Intelligence

Agente de BI

Uma proposta de agente que transforma arquivos de dados em painéis web interativos para apoiar decisões com mais clareza.

Demonstração com dados fictícios

O que o agente fará

O usuário envia uma planilha CSV ou Excel, informa qual decisão quer apoiar e escolhe indicadores. O agente analisa a estrutura dos dados, sinaliza limitações e prepara um painel HTML com métricas, gráficos e filtros. Este arquivo demonstra o formato do painel; a integração com inteligência artificial ainda precisa ser configurada.

Os filtros atualizam os indicadores e o gráfico.
